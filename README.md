Agregar
Seleccionar Clientes, Pedidos o Productos, completar el formulario y pulsar Registrar el ID se genera automáticamente. En pedidos, seleccionar un cliente existente.
Modificar
Buscar el registro en la tabla y pulsar Modificar cambiar los datos y pulsar Guardar modificación. La tabla mostrará los valores actualizados con el mismo ID.
Eliminar
Pulsar Eliminar en la fila correspondiente y confirmar no se puede eliminar un cliente que tenga pedidos asociados.
